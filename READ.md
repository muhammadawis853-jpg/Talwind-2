
# Travel Explorer Website

A responsive 3-page travel website built using HTML,
Tailwind CSS, and JavaScript.

## Pages
1. Home
2. Destinations
3. Contact

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Unsplash Images

## Features
- Responsive layout
- Navigation between pages
- Destination cards
- Contact form validation
- Interactive success message

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Navigate through all three pages.
